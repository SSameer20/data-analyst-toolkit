# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Data analysts and people using AI agent environments who want structured help with common analysis work. The user confirmed these are equal priority audiences.

## Product Purpose

The Data Analyst Toolkit provides reusable agent skills for common data analysis workflows. The site should help visitors explore skills, install the toolkit, and open the GitHub project. The user confirmed all three as homepage goals.

## Positioning

The toolkit groups six focused skills under an end-to-end analysis workflow. This is a description of the repository, not a comparative market claim.

## Operating Context

Skills are installed into compatible agent environments. The toolkit does not connect to databases, inspect live BI workspaces, or modify source datasets.

## Capabilities and Constraints

The six skills cover data analyst workflow, data quality, data cleaning, feature engineering, SQL, and business intelligence reporting. Generated queries, formulas, and reports should be reviewed before use. Artifact generation depends on tools provided by the host environment.

## Brand Commitments

The project is named Data Analyst Toolkit. The user requested a clean, light themed homepage and confirmed warm gray with green accents.

## Evidence on Hand

The repository README documents the six skills, installation methods, MIT License, project links, and support email. It states that the toolkit does not access live databases or BI workspaces and does not modify source datasets. The homepage includes an example quality review; it is illustrative and should not be presented as a customer result.

## Product Principles

- Preserve the six-skill hierarchy and the end-to-end workflow.
- Explain limits plainly and avoid claims the README does not support.
- Let visitors inspect a specialist skill before installing it.
